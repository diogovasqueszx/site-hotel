# Hotel Royal

Interface demonstrativa para consulta de hóspedes e quartos. Os dados apresentados são fictícios.

## Áreas
- `index.ejs` — página inicial
- `hospedes/` — listagem e detalhes de hóspedes
- `quartos/` — listagem e detalhes de quartos
- `login.ejs` — tela de acesso demonstrativa

O login não realiza autenticação nesta versão.
